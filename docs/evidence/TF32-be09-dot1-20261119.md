# BE-09 đợt 1 — AI

Nhánh: `trang/TF32-be09-quet-anh`. Ngày: 19/11/2026.

Thêm `POST /moderate/parts`, giữ nguyên `/moderate` cho client cũ. Cùng service JWT của Core, issuer/audience/caller được kiểm tra trước khi gọi provider.

Mỗi item bắt buộc là caption chỉ có text, hoặc image chỉ có một HTTPS URL. Tối đa 20 item, ID không trùng, caption tối đa 20.000 ký tự. Caption và mỗi ảnh gọi provider riêng; xử lý đồng thời tối đa 4 phần trong một request.

Kết quả theo ID và đúng thứ tự: `passed`, `flagged`, hoặc `error`, kèm categories, scores, model, errorCode. Timeout/provider error của một ảnh không xóa kết quả các phần khác. Lỗi không được trả thành passed; thông báo lỗi không chứa caption hoặc URL. ViSoBERT, nếu bật, chỉ tham gia caption. PII masking của pipeline text được giữ nguyên.

OpenAPI được xuất lại bằng `uv run python -m scripts.export_openapi`.

- `uv run ruff check .`: đạt.
- `uv run ruff format --check .`: đạt.

Các ca API thêm gồm tách đầu vào, partial failure, timeout, không lộ lỗi provider, auth, HTTPS, ID trùng và đầu vào hỗn hợp bị từ chối.
